# نَبْض | NABD

تواصل العائلة فقط: صوت وكتابة وصور ورسم، ونبضة تنادي الطفل حتى وهو يلعب.

من **WAMD ARC** · [wamdarc.com](https://wamdarc.com)

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | الواجهة والتصميم |
| `config.js` | **رقم الإصدار، ورابط السيرفر، ومفتاح الإشعارات العام** |
| `core.js` | التخزين على الجهاز والتشفير (مشترك مع sw.js) |
| `app.js` | الدخول، المحادثات، الصوت والصور والرسم، النبضة، المزامنة، التحديث التلقائي |
| `admin.js` | الإعدادات، الأفراد والصور الرمزية، أجهزة العائلة، النسخ الاحتياطي |
| `avatars.js` | الصور الرمزية |
| `sw.js` | العمل بدون إنترنت، والتحديث التلقائي، والإشعارات |
| `wamd-stats.js` | عدّاد الاستخدام المشترك لتطبيقات ومض آرك |
| `worker/worker.js` | السيرفر `nabd-api` (Cloudflare Worker + D1 باسم `nabd`) |

## النشر
- **التطبيق:** GitHub Pages من `main` على `nabd.wamdarc.com`.
- **السيرفر:** مربوط بهذا المستودع (Workers Builds)، أي رفع على `main` ينشر `worker/worker.js` حسب `wrangler.toml`.
- مفاتيح الإشعارات في جدول `config` داخل قاعدة `nabd`. مفتاح الإدارة يتحقق منه السيرفر عن طريق `siraj-api` (أو أضف `ADMIN_KEY` كمتغير سري).

## مع كل تحديث
غيّر `VERSION` في `config.js` و `CACHE` في `sw.js` و `?v=` في `index.html`. الأجهزة تتحدّث لحالها، والمدير يقدر يضغط «حدّث كل الأجهزة الآن».

## الخصوصية
- مفتاح العائلة ينولد على جهاز المنشئ، ويتشفّر بكود العائلة. السيرفر ما يشوف الأسماء ولا الرسائل ولا الصور.
- الرسالة تنحذف من السيرفر أول ما توصل لكل الأجهزة، وبحد أقصى ٣ أيام.
- الأرشيف على الأجهزة فقط، والنسخة الكاملة ملف يحفظه وليّ الأمر على جهازه.

## الصلاحيات
- منشئ العائلة **المدير الأساسي الدائم**: يعطي الإشراف لأي فرد ويشيله، والمشرفين ما يقدرون يشيلونه.
- المشرف: الأجهزة، التحديث، الحذف، الحذف التلقائي، الأفراد والصور الرمزية، كود العائلة.
- غير المشرف (حتى الأم): تنطبق عليه إعدادات الإدارة مثل الأبناء.
- الأطفال يتكلمون مع الأب والأم فقط (وكل العائلة في «العائلة»). النبضة للوالدين والمشرفين.
